# Huy Dev — Dark Developer Portfolio

Website portfolio cá nhân một trang, thiết kế nền đen/xanh neon, tương thích PC, tablet và điện thoại.

## Chạy trên máy tính
1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt.
3. Để trải nghiệm gần với môi trường hosting, có thể dùng VS Code + Live Server.

Không cần cài Node.js, không cần backend hoặc cơ sở dữ liệu.

## Cấu trúc
- `index.html`: nội dung các section và metadata SEO.
- `style.css`: giao diện, hiệu ứng, responsive.
- `script.js`: menu mobile, active navigation, reveal khi cuộn, sao chép số Zalo.
- `assets/favicon.svg`: favicon.

## Đưa website lên GitHub Pages miễn phí
1. Tạo hoặc đăng nhập tài khoản tại https://github.com/
2. Tạo một repository **public**, ví dụ `huy-dev-portfolio`.
3. Upload toàn bộ file trong thư mục này lên thư mục gốc của repository; đảm bảo `index.html` nằm ở thư mục gốc.
4. Mở **Settings → Pages**.
5. Ở **Build and deployment**, chọn **Deploy from a branch**.
6. Chọn branch `main`, folder `/(root)`, sau đó nhấn **Save**.
7. Chờ GitHub Pages triển khai và mở URL được hiển thị trong mục Pages. URL thường có dạng `https://TEN-TAI-KHOAN.github.io/huy-dev-portfolio/`.

Hướng dẫn chính thức: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Trước khi công khai
- Thay URL Facebook `https://www.facebook.com/` bằng đường dẫn trang cá nhân chính xác.
- Các dự án hiện là concept minh họa giao diện, không nên giới thiệu như dự án đã triển khai thực tế nếu chưa đúng.
- Google Fonts cần internet; nếu mất mạng, website dùng font dự phòng.
- Website tĩnh không có form, đăng nhập, trang quản trị hay backend theo phạm vi đã chốt.

## Chỉnh nội dung
Mở `index.html` bằng trình soạn thảo và tìm các tiêu đề như `Dự án nổi bật`, `Dịch vụ của mình` hoặc thông tin liên hệ để sửa. Sau khi chỉnh, tải các file mới lên repository để cập nhật website.
